# Auchan-

Application front-end de démonstration d’un catalogue e-commerce Auchan.

- [Présentation du projet](PRESENTATION.md)
- [Documentation technique](DOCUMENTATION.md)

Ouvrir `index.html` depuis un serveur web local pour que le chargement des données avec `fetch` fonctionne. Le catalogue initial se trouve dans `data/data.json`.
